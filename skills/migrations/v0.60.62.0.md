# Upgrade to v0.60.62.0: the brain links every page that names an entity

`gbrain extract --stale` now links every page that names a person, company or
account (by title, record-title subject, frontmatter alias or a declared code
such as `Account code: ACMX`) to that page. The `entity` card lists those pages
by type (`referenced_by`) with a `coverage` state, and `get_backlinks` pages
through them (`group: "page"`). `gbrain-base-v2` gains an `account` page type
(alias `crm`). Linking is free: no model calls.

1. **Finish the upgrade.** `gbrain upgrade` runs it. To be sure, on the brain
   host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   Migration v206 adds columns to `page_aliases` and three small tables; no
   existing row is rewritten. Restart every `gbrain serve`, autopilot and
   worker.

2. **Run the first mention pass.** `gbrain post-upgrade` prints an `[AGENT]`
   line with the page count and an estimate while pages are due. Run it now
   (free, resumable):
   ```bash
   gbrain extract --stale --catch-up
   ```
   Without it, autopilot cycles do the same work over several runs, and entity
   cards report `coverage.state: "pending"` until then.

3. **Verify.**
   ```bash
   gbrain extract --stale --dry-run --json   # mention_due_pages: 0
   gbrain entity "<an account or person name>"
   ```

4. **Tell the user about the off switch only if they ask, or if a name links
   wrongly.** `gbrain extract mentions --explain <name> --page <slug>` says why
   a name links or not. A wrong link is fixed by `mentions.ignore` (a name) or
   frontmatter `mention_ignore` (one page); `gbrain config set
   mentions.auto_link false` turns linking off and removes mention links on the
   next sweep. These change the user's brain: ask before setting them.

5. **Know the behavior changes.**
   - `extract --stale` JSON adds `mention_*` fields; `stale_remaining` counts
     link-stale pages plus mention-due pages.
   - A derived alias (record-title subject or declared code) never answers for
     another page's exact title, so `entity("Acme Example")` stays the company
     page beside a `CRM record: Acme Example` page.
   - Search's alias hop also resolves declared codes.

Guide: `docs/guides/entity-recall.md`.
