# Upgrade to v0.60.61.0: paid queued jobs carry the user's approval, one MCP tool surface, HTTP status mode

Four behavior changes reach existing brains. Paid commands that queue work
(`book-mirror`, `enrich --background`, `jobs submit enrich|subagent`) ask for
consent before queueing and the worker holds them to the approved total. New
stdio registrations use the `starter` tool surface. A `gbrain serve --http`
that cannot open its brain stays up in status-only mode. Stdio MCP sessions
receive onboarding coaching notices.

1. **Finish the upgrade.** `gbrain upgrade` runs it. To be sure, on the brain
   host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   Migration v205 adds the spend-authorization columns to the job queue.

2. **Restart every worker, `gbrain serve` and autopilot.** Only upgraded
   workers claim jobs that carry a spend authorization; an older worker stops
   claiming at the first such job in its queue. Check:
   ```bash
   gbrain doctor --only legacy_job_authority --json
   ```

3. **Tell the user about queued paid jobs from before the upgrade.** A
   `book-mirror` or `enrich` job queued before this release runs as
   `legacy_default` under a $5 cap (enrich: its own `--max-usd` when set). A
   chapter on an expensive model can stop with `derived_cap_exhausted`;
   rerunning the command skips completed chapters. List them:
   ```bash
   gbrain jobs list --json
   ```
   Cancel a group only with the user's agreement:
   `gbrain jobs cancel --group <id>`.

4. **Expect consent prompts on background paid work.** `gbrain enrich
   --background` and `gbrain jobs submit enrich|subagent` exit 3 with the
   consent payload unless the user authorized the spend (`--yes`,
   `--max-usd <usd>`, a preapproval or `spend.posture=tokenmax`). Relay the
   estimate to the user and rerun `fix.argv` after they agree.

5. **Know the tool surface.** New stdio registrations (readiness fix, init,
   `bootstrap hooks`, plugins) pin `--surface starter`. Existing registrations
   keep their surface. A stdio session that needs a hidden tool calls
   `request_tools` with `{ "surface": "full" }`; `mcp.allow_session_widen=false`
   turns that off. Stdio `serve` honours `GBRAIN_SURFACE`.

6. **Shared HTTP brains.** A `gbrain serve --http` whose brain is locked,
   missing or unconfigured answers `/health` with 503 and `Retry-After: 5`
   and recovers on the same port once the brain opens. Container health
   checks that need the old exit use `--fail-fast` or
   `GBRAIN_SERVE_FAIL_FAST=1`. After recovery, clients re-list tools or
   reconnect.

Rolling the binary back leaves queued spend-authorized jobs unclaimable;
cancel them first with `gbrain jobs cancel --group <id>`.
