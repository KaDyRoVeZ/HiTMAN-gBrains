# Upgrade to v0.60.53.0: automatic facts on PGLite, scoped dashboard keys

Two behavior changes reach existing brains. On PGLite, `gbrain serve` now
turns queued pages into facts on its own, which spends money on the
configured facts model. New admin-dashboard API keys get read and write, not
admin, unless the user ticks admin.

1. **Finish the upgrade.** `gbrain upgrade` runs it. To be sure, on the brain
   host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   Migration v202 converts every legacy token grant to the grant columns
   without changing what any token can do; v203 adds per-client source and
   takes-holder columns. Restart every `gbrain serve`, autopilot and worker.

2. **Tell the user about the automatic facts drain (PGLite only).** It is on
   by default. Each extracted page is one paid chat call, capped at $1 per run
   and $5 per rolling day. Show the state:
   ```bash
   gbrain doctor --only facts_drain --json
   ```
   If the user does not want automatic extraction, run
   `gbrain config set facts.extraction_enabled false` after they say so. Raise
   a cap (`facts.drain_budget_usd`, `facts.drain_daily_budget_usd`) only with
   their agreement. Guide: `docs/guides/facts-drain.md`.

3. **Show the user any full-access API keys.**
   ```bash
   gbrain doctor --only legacy_token_null_scope --json
   ```
   Each listed key can do everything, including admin. Ask the user which
   keys need admin; narrow the rest with the printed command, for example
   `gbrain auth rescope --id <token-id> --scopes read,write`. Never narrow a
   key without the user's agreement: an agent using it may lose access.

4. **Check the repairs this release adds.**
   ```bash
   gbrain doctor --only revision_backfill,legacy_token_grant_shape --json
   gbrain repair take-supersession          # preview; writes nothing
   ```
   Follow `revision_backfill`'s printed command if it warns. Show the user the
   take-supersession preview before running it with `--apply`.

5. **Know the new options.** `gbrain auth rescope --client <id> --sources none`
   gives an OAuth client no source access without rotating its secret;
   `--takes-holders a,b|none` sets which takes it can read.
