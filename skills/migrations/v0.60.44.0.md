# Upgrade to v0.60.44.0: a cheaper gbrain per agent task

This release makes every MCP tool call cheaper for the agent that makes it.
Search and query results are smaller, tool results are compact JSON, the
starter tool list is less than half its old size, and search skips work it
does not need. Nothing here changes what gbrain finds. No schema migration
runs and nothing spends money.

1. **Restart every `gbrain serve`** after upgrading, so stdio servers pick up
   the new tool list and row shape.

2. **Know the new row shape.** Remote MCP callers (any harness talking to
   `gbrain serve`) now get lean `search` and `query` rows: `id`, `slug`,
   `title`, `type`, `chunk_text`, `score`, `effective_date`, `source_id`,
   `chunk_id`, `evidence`, `create_safety`, and every safety or provenance
   marker that is present. Ranking diagnostics (`page_id`, `chunk_index`,
   `chunk_source`, `keyword_hit`, `cosine`, `base_score`, boosts) are gone
   unless asked for. `_meta.retrieval.rows` says which shape came back.
   - To get every field for one call, pass `fields: "full"`.
   - If a script or client around this brain reads a dropped field, keep the
     old rows for every remote caller with the user's agreement:
     ```bash
     gbrain config set mcp.result_rows full
     ```
     then restart `gbrain serve` (OAuth HTTP picks it up on the next request).
   - The gbrain CLI on a thin-client install keeps full rows on its own once
     it is on this release. An older thin CLI gets lean rows until it is
     upgraded or the host sets `mcp.result_rows full`.

3. **Expect shorter tool descriptions.** The longer guidance for each starter
   tool is in `docs/mcp/TOOL_REFERENCE.md`. Read it when a tool's default is
   unclear. Notices about saved facts and other names under search results
   are capped (1,500 and 400 characters, whole items, with a `(+N more)`
   count); `recall` returns the full set of facts.

4. **Verify:**
   ```bash
   gbrain doctor
   gbrain config get mcp.result_rows    # empty means lean rows for remote callers
   ```
