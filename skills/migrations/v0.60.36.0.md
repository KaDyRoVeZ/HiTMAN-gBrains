# Upgrade to v0.60.36.0: fix wave 8

This release changes how writes report back, how legacy tokens are granted,
and several defaults. Most of it needs nothing from you. The steps below are
the ones an agent or a script around gbrain should know about.

Paid work and grant changes need the user's agreement. Never run
`gbrain embed --stale`, a repair with `--apply`, or `gbrain auth rescope-token`
on the user's behalf without asking.

1. **Finish the migration.** `gbrain upgrade` runs it. To be sure, run on the
   brain host:
   ```bash
   gbrain apply-migrations --yes --no-autopilot-install
   ```
   Three schema migrations run (v190-v192): upstream-observation columns on
   `sources`, alias rows that cascade with their source (orphan alias rows
   left by earlier source removals are deleted), and take-vector identity
   columns. A brain created before v150 also backfills page revisions in
   batches; it prints progress, is safe to interrupt and resumes on the next
   run. Until a page's revision is backfilled, a write that names a revision
   for it is refused with `revision_backfill_pending`.

2. **Pending writes exit 10, not 1.** A CLI write that was accepted but had
   not committed when the wait ended (30 s by default) now exits 10 and
   prints its receipt. Exit 0 still means committed and 1 still means failed.
   Scripts that treat any non-zero exit as failure should either check for 10
   or pass `--accept-pending` (or set `GBRAIN_ACCEPT_PENDING=1`). Do not
   resubmit a pending write with a new request id. Replay it with the same
   `request_id`, or poll it:
   ```bash
   gbrain call get_write_request '{"request_id":"<id from the receipt>"}'
   ```
   `--wait <seconds>`, `GBRAIN_WRITE_WAIT_MS` or
   `gbrain config set persistence.write_wait_ms <ms>` change the wait.

3. **Legacy tokens: an empty source list now means no sources.** A legacy
   bearer token whose stored `source_id` is an explicit empty list used to
   fall back to `default`; it is now refused for every operation. Regrant
   explicitly when the user agrees:
   ```bash
   gbrain auth rescope-token <name> --sources default        # or a,b
   gbrain auth rescope-token <name> --reset-default sources  # back to the default
   ```
   A rerun of bootstrap harness rotation carries the old token's grants and
   no longer adds operations that are newer than the token. Preview what it
   withheld and widen only by name:
   ```bash
   gbrain auth rescope-token <name> --refresh-operations
   gbrain auth rescope-token <name> --refresh-operations --add <op,...>
   ```

4. **Ask before embedding takes.** Takes are now embedded with pages by
   `gbrain embed --stale` and the cycle's embed phase, and existing take
   vectors are re-embedded once so they record their model and claim. That
   calls the embedding provider and can cost money. `gbrain doctor`
   (`fact_take_vectors`) counts what is missing. To turn it off:
   `gbrain config set takes.auto_embed false`.

5. **Know what else is on by default.** Dream reads imported
   `type: conversation` pages when a corpus directory is set
   (`gbrain config set dream.synthesize.conversation_pages false` turns it
   off). Atom extraction of connector email and meeting pages is on again
   (`gbrain config set cycle.extract_atoms.connector_pages false`). Both call
   the configured models.

6. **Expect some doctor checks to turn yellow.** Checks that could not verify
   anything now warn "not verified" instead of reporting ok, `sync_freshness`
   reports a remote source whose upstream was not checked in 24 hours as
   "upstream unknown", and `auto_chronicle` reports that `auto_chronicle=true`
   has no effect yet. Each warning names its fix.

7. **Re-derive markdown link types if you rely on them.** The bundled packs'
   bare-word verb regexes no longer type markdown links (a nearby "started"
   or "joined" no longer makes a link `founded` or `works_at`). To redo
   existing links: `gbrain extract links --source db`.

8. **Verify:**
   ```bash
   gbrain doctor
   gbrain remember "upgrade check" --provenance upgrade; echo "exit=$?"
   ```
   `exit=0` means the write committed.

9. **If any step fails,** file an issue at
   https://github.com/garrytan/gbrain/issues with the output of
   `gbrain doctor` and `~/.gbrain/upgrade-errors.jsonl` if it exists.
