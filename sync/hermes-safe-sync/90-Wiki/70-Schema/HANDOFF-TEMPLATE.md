# Шаблон предложения в LLM Wiki

Создай файл только при явном поручении сохранить знание. Путь: `40-Agents/20-Handoffs/<runtime-profile>/<UTC-timestamp>-<slug>.md`. Перед созданием проверь отсутствие файла; существующий чужой файл не перезаписывай. Заполни все угловые placeholders фактическими значениями. Timestamp бери инструментом, источник — реальный, а не пример. Профиль `default` при одобренной канонической записи не обязан создавать handoff самому себе.

```yaml
---
schema_version: 1
id: <unique-stable-id>
type: review-item
title: "<один предмет>"
status: proposed
created_at: <ISO-8601>
updated_at: <ISO-8601>
privacy: <public|personal|sensitive|restricted|secret-ref>
source_refs:
  - "<точный URL/локальный путь/ID + раздел или строки>"
origin_profile: <фактический runtime profile ID>
source_mode: <safe-copy|reference-only>
outcome: <New|Update|Disputed|Review required>
proposed_target: "90-Wiki/20-Knowledge/<область>/<заметка>.md"
approval_ref: "<ссылка/идентификатор конкретного поручения; без полного диалога>"
ledger_ref: null
---
```

## Предлагаемое изменение
Короткий проверяемый факт/правило/процедура. Отдельно: факт, вывод, неопределённость. Не включать секреты и чувствительные оригиналы.

## Источники и проверка
- Где именно подтверждается каждое утверждение; дата источника и дата проверки.
- Что реально проверено инструментами, что пока не проверено.
- Для reference-only — допустимый locator без содержимого оригинала и без секретных параметров URL.

## Проверка дублей и конфликтов
- Какие запросы/заметки просмотрены, почему это New или Update.
- Текущая версия целевой заметки: hash/дата проверки, если она существует.
- Расхождения: обе версии с источниками; условие разрешения. Не стирать старую версию молча.

## Критерии принятия default
- [ ] Согласие относится к этому материалу и целевому пути.
- [ ] Источник проверен; privacy и source_mode соответствуют содержимому.
- [ ] Нет дубликата, секретов, полных переписок и чувствительных оригиналов.
- [ ] Все обязательные поля SCHEMA заполнены; ссылки ведут в существующие цели.
- [ ] Каноническая заметка, связанные индексы и журнал проверены после записи.

## Статус передачи
Изначально: «предложение сохранено, не принято». Отдельно укажи фактический канал/ID передачи, только если передача выполнена. Наличие файла не доказывает уведомление, принятие или завершение.
