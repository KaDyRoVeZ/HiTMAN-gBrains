# Postgres 15 compatibility lane (#7112; e2e.yml job postgres15-compat).
#
# gbrain supports Postgres 15 (migration v011 refuses older servers), while
# PGLite runs Postgres 17 and every other Postgres lane runs 16, so SQL that
# only 16+ parses ships green everywhere else. This lane runs a targeted set of
# the write, sync, jobs and migration files against pgvector/pgvector:pg15.
# Every file applies the whole migration chain to a fresh database first.
#
# Left out on purpose: the catalog goldens (schema-catalog-golden,
# schema-migrations-replay) pin pg_get_viewdef text, which Postgres 16 deparses
# differently, so they hold Postgres 16 output by design.
